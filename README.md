## 📄 설명
저희 팀은 디자이너 1명, 개발자 3명으로 구성된 4인 팀으로, 무박 3일 동안 "빵"이라는 주제로 인디게임잼 프로젝트를 진행했습니다.  
적은 인원을 효율적으로 운영하기 위해 각자 스테이지를 나누어 개발하고, 이를 하나로 합치는 방식으로 작업을 구상했습니다.  
‘빵’이라는 주제를 "재료를 올려 완성하는 결과물”로 해석하여, 재료를 던져 빵 위에 올려 새로운 빵을 만드는 2D 캐주얼 퍼즐 게임을 제작했습니다.  
<br>
### 👉 특징
- 단순하고 직관적인 드래그 앤 드롭 조작
- 스테이지마다 다른 빵들이 등장하는 개성
- 짧은 기간과 적인 인원수에도 효율적인 분업과 협업으로 완성
